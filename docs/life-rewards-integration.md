## 1. 權威與取代
以 [v1.5 經濟決策](v1.5-economy-decisions.md) 為準。本稿取代舊生活榮譽每日3／專案12、每月兩焦點案、生活只換外觀、七日補登占原日期額度，以及每日核帳提案。舊研究留在 Git 歷史，不作實作依據。
生活成果賺軍需，主要買裝備；戰鬥提供XP／目錄及故事資格，不循環刷軍需。軍需不能買器官、跳過兵種資格或替使用者完成真實任務。

## 3. 帳本與更正
新軍需錢包0起算、開局一次+40，介面可沿用榮耀；舊RP/glory唯讀歷史。
記帳刪除沖銷並釋放當日名額；新增後五秒「復原」是撤銷新增，等同刪除，不是重新發獎。里程碑取消／刪除、專案刪除依來源沖銷。已發獎鎖定不妨礙合法撤銷，但撤銷不是換一個新成果再領的捷徑。
餘額允許負數；負時不能購買，已購裝備不收回，不向使用者收現實金錢。
唯一來源鍵與完成狀態、配額、交易需一致結算；重送／跨裝置／規則升版不能多領。具體交易方案由Claude規劃。
成長紀錄可與合法核心軍需同時給，兩本紀錄用途和上限分開；同一成果跨入口不重複軍需。一般記帳不算飛昇成長。
離線可記錄但未確認獎勵不可花；不能把客戶端支出日期當伺服器記錄日以回補額度。

## 4. 取得速度與裝備
20日每天一核心＋一筆真實記帳=600；三核心＋三筆記帳=1800；再加一個合資格完整專案=1920，均不含開局40。每日核心與記帳合計最高90；專案不限數量，沒有合計月硬上限。
既有候選裝備價格保留，見v1.5；電漿240按90／日約三個滿額日，不再寫五至六日。收入改定使裝備購買更快，需測多人配裝、低完成頻率與長期耗用，不能擅自提高價格。
角色／武器授權與軍需購買分開：存到錢不等於可買阿斯塔特或器官。免費配發／借用不可回收生錢。

## 5. 生活約束（第三輪G1／D2／B1及R1／S2／E1已定）
G1已定：完成至少一合法今日核心才可開當日新正式行動，續玩／訓練／軍械庫／資料不鎖；休息／明示豁免可開新行動，不發軍需。記帳不是門檻。
D2已定：自啟用或上次整頓後累積三個失約日（非滾動七日），進入待整頓；完成事先指定的整頓成果清本輪計數，才可開新行動。只對已預定、到期未完成核心每日一次。G1與D2均須满足，整頓成果可事先合法指定為核心，一次完成滿足兩者。普通休息不清既有D2。
B1已定：09:00前指定一位候選人與最多兩個不同領域成果，之後只可在活動前替換未完成項，不改人／增額；同任務可兼核心與成長、各一次、獨立限額。
模式C：背景相容新候選人主線＋明示原創的原士兵路線；首戰團極限戰士。飛昇首次上線後另排。
舊腐化仍凍結，不匯入D2，不扣裝備或角色，不啟用永久叛變。

第三輪已定 R1／S2／E1：
- R1整頓：開始前確認一個可驗收成果與完成條件；完成時勾選並填一句成果摘要，不要求照片／定位／證明。只可換成尚未開始的等價成果並留變更紀錄，不事後認列已完成事情。
- S2休息：依使用者時區週一至週日最多兩天，當日09:00前設定；已發生日期及已結算失約不能移走重用。免當日G1與失約結算，不清既有D2累計或待整頓。
- E1豁免：疾病／照護／突發／其他必要原因，不設硬上限，至少選一理由；自訂理由僅短摘要，不存敏感證明。28日內三次以上只提示檢視目標，不懲罰、不禁止。
- 當日有效豁免可開新正式行動並免當日失約；待整頓時只暫緩當日門檻，不算完成整頓、不清累計，次日依原狀態恢復。舊失約補記豁免須逐日更正並重算，不一鍵清歷史。豁免本身不發軍需或成長紀錄。


## 6. 舊制遷移
舊任務／專案／器官／部隊／腐化／RP與榮耀完整保留唯讀；不按比例兌新軍需，不偷偷將舊收藏轉精銳。
停止舊每分鐘腐化、駐軍減員、滅絕令鎖畫面及代做真實任務的伺服顱骨依既定決策執行；此文件不聲稱已完成。
切換前由Claude提出預覽、備份／回復與未完專案剩餘成果處理。不得沿用舊「兩焦點案／剩餘8點」遷移；未核准的歷史回補與部分完成專案權益不自行推算。
同一新事件只走一套經濟管線，不同時領RP、舊榮耀、行動點、腐化減免和新軍需。遷移正式資料需使用者確認。

## 8. 回饋美術
完成提示分開顯示來源、軍需與成長紀錄；記帳顯示今日已獲獎筆數0–3，核心顯示09:00名額與已完成，專案顯示本案里程碑／結案權益，不再顯示核帳領獎按鈕或每月兩案名額。
超額記帳仍保存真實資料，提示已達今日獎勵額度，不叫使用者為明天獎勵延後記錄。負餘額顯示沖銷來源，不製造角色受傷敘事。
