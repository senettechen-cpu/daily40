最新修正請以 [星界軍造型與掩體射擊修正](guard-cover-revision.md) 為準。已替換友軍身體素材、增加方向性掩體與射擊陣地選擇；下文「不主動尋找掩體」等早期限制已被這次更新取代。

## 無聲動畫版（Animation Pass 02）

使用者確認不需要聲音。本版沒有音效、音訊權限或自動播放音訊。

- 戰場改為斜俯視投影：擠出厚度的平台、立體箱體、光暈、地面細節與深度排序。
- 角色改為程式繪製的分層人形：頭盔、肩部、胸甲、腿部、背包與可替換武器；角色列表與戰场沿用相同造型。
- 角色移動以 4–6 個模擬 tick 平滑呈現，附帶步態；射擊有手臂後座，近戰有揮擊。
- 武器事件明確包含來源、目標、武器種類與發生時間；彈道、火焰、命中火花、飄字和受擊皆依此播放。
- 血條在視覺命中時間（0.16 秒）更新；模擬結算不變。畫面插值和動畫不參與命中或傷害計算。
- 新增倒地傾倒、重擊輕微震屏與「減少動態」選項；初始尊重系統偏好，需觀看完整演出可取消勾選。
- 暫停凍結演出時間。仍屬程式美術動畫樣板，不宣稱達到 Tacticus 的正式模型、材質和動畫製作品質。

驗證：`node --test tests/expedition-presentation.test.cjs tests/expedition.test.cjs`。下文原型範圍與限制仍適用，原先格移動示意已由平滑斜俯視演出取代。

入口：啟動 `npm run dev -- --host 127.0.0.1` 後開啟 `/expedition-preview.html`。原 `/visual-preview.html` 頂部也提供連結。

這是獨立、開發環境限定的原型，不包含在正式 production HTML 入口內；不讀取或寫入既有 GameContext、登入帳號、遊戲資源或雲端存檔。重新整理會重設。需正式部署時應另行加入產品路由與持久化，不能只上傳現有 `dist` 並期待此預覽頁存在。

## 已實作

- 四名人類伙伴、四種武器、六件唯一裝備；明確角色資格、裝備占用和部署通道檢查。
- 原生 SVG 俯視戰場與人物，雷射、霰彈、精準槍、火焰器的武器外形不同。
- 16×10 格碼頭、障礙繞路、視線阻擋、掩體命中減益、扇形火焰多目標攻擊。
- 近戰衝鋒者、射手、提供附近命中增益的指揮兵，三波守軍。
- 自動交戰優先：最近／指揮兵／受傷敵人。戰前設定，出擊後鎖定。
- 醫護自動治療；清除三波後，自動接近並修復信標，技師修復較快。
- 暫停、1×／2×、同引擎快算、獨立原型安全撤離；切換分頁自動暫停。
- 倒地、失敗、勝利、時間上限和戰報；傷害、承傷、治療、剩餘生命統計。

## 本輪限制／相對設計稿的簡化

- 此次僅交付設計稿 A 階段，未加入 XP、升級、裝備強化、故事、基地、永久存檔或其他三張任務地圖。
- 原型使用格移動及程式繪製示意圖，非正式角色美術或完整動作素材；音效尚未加入。
- 武器視覺與數值皆源自相同 weapon ID，但正式裝備資料還需擴充動畫、供能、工具及手部槽位。
- 暫無壓制、後撤保持射程、戰中改令、倒地救起與正式撤離區機制；安全撤離是原型測試功能。
- AI 檢查掩體對命中的影響，但不會主動評估所有掩體位置的戰術價值。
- 三波間沒有額外等待。初始平衡模擬平均約 27 秒，低於設計稿 60–120 秒目標；目前定位為短教學，後續延長應增加目標決策而非單純增加敵人血量。
- 固定種子 40126 方便比較武器，沒有正式隨機掉落、獎勵、存檔或伺服器驗證。

## 驗證

`node --test tests/expedition.test.cjs`：裝備相容與唯一性、部署占用、視線、不可變輸入、固定種子重播、步進一致性、地圖碰撞、治療、火焰效果、終局與撤離。

100 個固定種子（1–100）的預設配置測試：100 次通關，平均 27.4 秒。這只是基準配置的教學可完成性，不代表所有武器與陣容已達平衡；尚需測試更多配置及真人試玩。

`npm run build`：TypeScript 包含原型檔案檢查；正式 Vite 入口維持原遊戲。
