## 4. 兩個數值待你或使用者定案（企劃，非美術）

這兩個是我實作時填的**候選值**，規格裡沒有，程式已標註為候選並寫在註解裡。需要你評估後給正式值，或確認沿用。

### 4.1 等級 XP 曲線

v1.5 §4 定了等級門檻的**意義**（4 級選路線任務、7 級選專精、10 級解鎖老兵人物任務與飛昇申請），但沒給 XP 數字。我目前填的是：

```
Lv1..Lv10 累計 XP = 0, 100, 250, 450, 700, 1000, 1350, 1750, 2200, 2700
```

需要的資訊：一場戰鬥大約給多少 XP，才能推算到 10 級要打幾場。目前戰鬥還沒有 XP 發放，所以這條曲線完全沒有實測依據。

### 4.2 甲殼甲護甲值

v1.5 §6 給了防破片甲 20、動力甲 80，但甲殼甲只寫「需資格，移動代價須測」，沒有數值。我暫填 **40**，並在程式註解標明未經審查。

同時需要「移動代價」的具體形式：是降低移動速度、增加進入掩體時間，還是別的？目前模擬沒有這個機制。
