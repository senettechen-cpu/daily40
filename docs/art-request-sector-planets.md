# 素材需求：星區節點星球（給 GPT）

開立日期 2026-09-24。Claude 撰寫技術規格，美術方向與最終畫面由 GPT 決定。

## 1. 要解決的問題

星區地圖上的 12 個節點（M1–M12），目前的星球是**純 CSS 漸層**畫的球體
（`src/command-deck.css` 的 `.sector-node__sphere`），只靠一個顏色變數區分世界類型。
使用者希望換成真正的美術素材。

## 2. 重要：交付的是 5 張，不是 12 張

節點的「世界類型」**不綁月份，綁當月的專案數**，會隨使用者增減專案即時改變
（`src/contexts/GameContext.tsx` 的 `getTraitForMonth`）：

| 當月專案數 | 世界類型 | 代號 | 既有主色 |
| --- | --- | --- | --- |
| 0 | 荒蕪世界 (Lv0) | `barren` | `#71717a` 灰 |
| 1–2 | 巢都世界 (Lv1) | `hive` | `#10b981` 翠綠 |
| 3–4 | 聖地世界 (Lv2) | `shrine` | `#a855f7` 紫 |
| 5–7 | 鑄造世界 (Lv3) | `forge` | `#f59e0b` 琥珀 |
| 8+ | 死亡世界 (Lv4) | `death` | `#ef4444` 紅 |

同一個月份（例如 M3）今天可能是巢都世界，下週加了專案就變成鑄造世界。
**所以素材必須按世界類型製作，不能按月份。** 一個月份用哪一張由程式即時決定。

既有的 `public/planets/m1.png`–`m12.png`（指揮中心對話框頂部的橫幅背景）
維持不動，不在這次需求範圍內。

## 3. 交付清單

5 種世界 × 2 種尺寸 = **10 個檔案**。

| 檔名 | 尺寸 | 用途 |
| --- | --- | --- |
| `sector-barren-96.webp` / `sector-barren-192.webp` | 96×96 / 192×192 | 荒蕪 |
| `sector-hive-96.webp` / `sector-hive-192.webp` | 同上 | 巢都 |
| `sector-shrine-96.webp` / `sector-shrine-192.webp` | 同上 | 聖地 |
| `sector-forge-96.webp` / `sector-forge-192.webp` | 同上 | 鑄造 |
| `sector-death-96.webp` / `sector-death-192.webp` | 同上 | 死亡 |

命名與既有裝備素材同規則（`<id>-<寬度>.webp`），Claude 匯入時不改檔名。

## 4. 技術規格

**格式**：WebP，**必須帶透明通道**。

**畫布**：正方形，星球圓盤**滿版內切**（圓盤直徑 = 畫布邊長），四角透明。
不要留白邊，不要在畫布內縮小星球。

**實際顯示尺寸**：90×90 CSS 像素。192 版供高解析螢幕使用（約 2.1 倍）。
請確認 96 版縮到 90px 時細節仍讀得出來——這是很小的圖，紋理不能太碎。

**光源**：左上約 28% / 24% 位置為亮部，右下為暗面。
這與目前 CSS 球體一致，換圖後不會和節點其他元素打架。
**陰影與明暗請畫進圖裡**，程式端會移除原本的 CSS 內陰影。

**周邊元素**（不要畫進去，程式會疊在外面）：
- 金色進度環（`#dfbc72`）畫在圓盤外圈，不會蓋到星球
- 要塞化時右下角會疊一個小徽章
- 不要畫軌道環、不要畫星環、不要畫文字或數字

**背景**：節點底色是 `#101925`（深藍黑）。星球邊緣請確保在這個底色上看得出輪廓，
暗面不要暗到與背景融在一起。

**容量**：參考既有裝備素材，96 版單檔 ≤ 4KB、192 版單檔 ≤ 12KB。
（現有裝備素材 96 平均 1.1KB、192 平均 3KB，可以更寬裕但不要失控。）

## 5. 風格方向

戰鎚 40K 星圖介面上的星球，不是天文攝影。與既有裝備／立繪素材同一個世界觀，
偏低飽和、重氛圍。主色請沿用第 2 節表格的既有色票（那個顏色已經寫在程式裡，
是各類型的識別色），但不必是單色球，可以有大氣、雲帶、地表明暗變化。

各類型的意象（供參考，最終由 GPT 判斷）：

- **荒蕪**：無人的岩石球，灰白，坑洞，無大氣或極稀薄
- **巢都**：夜面有密集人造燈火，翠綠的大氣光暈，地表看得出巨型結構
- **聖地**：紫調，寧靜，或有極光般的光帶，少量地表光點
- **鑄造**：琥珀／橘紅，工業汙染的厚重雲層，地表有熔爐般的熱點
- **死亡**：紅，敵意，風暴或裂痕，讓人一眼覺得不該登陸

五張放在一起要能**一眼分辨**——使用者是在一排 12 個節點裡掃視，
不是逐一細看。輪廓與色調的差異比細節重要。

## 6. 驗收標準

1. 10 個檔案齊全，檔名與第 3 節完全一致
2. 帶透明通道，四角透明，圓盤滿版
3. 縮到 90px 顯示時五種類型可辨識
4. 在 `#101925` 背景上邊緣清晰
5. 容量符合第 4 節
