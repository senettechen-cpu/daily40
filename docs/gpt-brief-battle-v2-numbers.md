## 你要決定的四張表

### 表一：傷害類型 × 護甲類型係數

這是整套設計的核心。目前 18 件裝備裡**只有雷射槍和雷射手槍有戰鬥數值**，
其餘 16 件帶上場完全不生效。有了這張表，每件武器只要填五個欄位就能參戰。

Claude 的候選值（未經驗證，可整份推翻）：

| 傷害類型 ＼ 護甲類型 | 無甲 | 布甲／防破片 | 硬甲／甲殼 | 動力甲 |

| 雷射 las | 1.0 | 1.0 | 0.8 | 0.6 |
| 爆彈 bolt | 1.0 | 1.1 | 1.0 | 0.9 |
| 電漿 plasma | 1.0 | 1.2 | 1.4 | 1.5 |

設計意圖：換裝備要真的改變打法，不只是數字變大。傷害類型可以增減，不必照上表。

### 表二：18 件裝備的戰鬥數值

每件武器五個欄位：

| 欄位 | 意義 |
| --- | --- |
| `damage` | 單次命中的基礎傷害（未計護甲） |
| `hits` | 一次攻擊嘗試幾次命中 |
| `range` | 射程，單位是六角格 |
| `damageType` | 表一的類型 |
| `penetration` | 無視的護甲點數 |

目錄（`shared/armory/catalog.ts`）：

```
主武器：制式雷射槍 40、霰彈槍 80、精準雷射槍 120、火焰器 120、
        電漿槍 240*、星界軍重武器組 200*、修女用爆彈槍 180*、阿斯塔特用爆彈槍 280*
副武器：制式雷射手槍 30
護甲：  防破片甲 60（護甲 20）、甲殼甲 160*（護甲 40）、阿斯塔特制式動力甲 400*（護甲 80）
工具：  醫療工具 80、通訊工具 80、工程工具 80
改裝：  功能改裝 60、整備一階 40（+5% 原始傷害）、整備二階 80（再 +5%）
```
（數字是軍需價格；`*` 是需要授權的項目。）

三種護甲另外要指定 `armourType`（對應表一的欄位）。

**工具目前在戰鬥中沒有作用**，請一併決定：是給被動效果，還是明確定位成「不影響戰鬥」。

## 一份實測數據給你參考

用佔位值跑一場 6v6（11×9 棋盤、含掩體高地險地、雙方同等裝備）：

```
結果: timeout（10 回合打不完）
行動數: 76
存活: 我方 2 / 敵方 1
```

也就是**傷害相對血量太低**，雙方磨到超時、幾乎同歸於盡。
這是佔位值的問題，正好說明表二、表三要往哪個方向調。

判斷基準（使用者可再調整）：
- 一場正常的 6v6 應該在幾回合內分出勝負？（目前上限 10 回合）
- 打贏的一方應該剩幾個人？
- 「配裝正確」相對「配裝隨便」，勝率差距應該多大？

## 戰場規格（給數值當背景）

- 六角格，11 欄 × 9 列，共 99 格
- 我方部署在最下兩列、敵方在最上兩列，出發距離約 6–7 格
- 地形：開闊／掩體（遠程傷害 ×0.75、進入即停止移動）／高地（射程 +1、命中 +10、進入花 2 移動力）／障礙（不可進入、擋視線）／險地（回合結束扣 5）
- 每次啟動 = 移動 + 一個行動
- 回合上限 10，超時算平手（不發完整獎勵）
