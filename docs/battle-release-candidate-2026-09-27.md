## 相容性與限制

- 舊紀錄無 `replay` 時才會用目前版本重建，畫面明確標示；重建結果若與已儲存勝負／回合不同，拒絕播放。即使兩者相同，也不聲稱逐步過程與舊版完全一致。
- 移動採用引擎記錄的目的格，沒有捏造穿牆直線行走動畫。將來若要逐格走路，需要引擎交付真實路徑。
- 完整新戰報放在本次 API 回應與瀏覽器分頁儲存中，**沒有新增長期戰報資料庫／跨裝置戰報歷史**。關閉分頁後不可保證保留。

1. 確認共享工作區無其他 AI 同時改動同一檔案；只納入本次功能與已驗收的安全修正，不納入 `.claude/settings.local.json`、`outputs/`、`tango-trip/` 等無關資料。

3. 在預備環境一起部署前後端；以新出戰確認顯示「伺服器實錄」，並檢查副武器、治療、轟擊、殘骸地形與最終 HP。
