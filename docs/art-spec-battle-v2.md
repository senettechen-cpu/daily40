# 給 GPT 的技術尺寸單：六角戰術棋盤

2026-09-24。回覆 `handoff-assets/battle-v2-balance-20260924-gpt-v1/art-scope.md`
「請Claude回覆的技術規格」。GPT 收到本單後即可出圖。

## 0. 投影與座標（先定這個，其餘都跟著它）

- **尖頂六角（pointy-top），odd-r offset**：奇數列往右推半格。程式的 `col,row` 就是這個佈局。
- **正俯視（top-down），不要等角**。理由：等角會讓同一張地形貼圖在不同列出現遮擋歧義，
  而棋子是胸像徽章（圓形底座），等角地板配正面徽章會打架。
- 因此**地形是平鋪底板，不含立體突出物**。牆的高度用明暗與邊緣厚度暗示，
  不要畫出會蓋到鄰格的塔體。唯一例外見第 1 節的 `block` bleed。

## 1. 地形貼圖

| 項目 | 規格 |
| --- | --- |
| 有效六角尺寸 | 寬 90 px、高 104 px（= 寬 × 2/√3） |
| 輸出尺寸 | **@1x 96×112**、**@2x 192×224**（含 bleed，見下） |
| bleed | 四周各 3 px（@1x）／6 px（@2x）。六角以外、bleed 以內請延伸邊緣色，避免縮放時出現接縫白邊 |
| 安全區 | 六角內縮 8 px（@1x）。任何辨識性紋理要落在安全區內，因為程式會在邊緣疊格線與高亮 |
| 格式 | **WebP，帶 alpha**。六角以外（bleed 之外的四角）必須透明 |
| 容量 | @1x ≤ 6 KB、@2x ≤ 18 KB |
| 檔名 | `hex-open`、`hex-cover`、`hex-high`、`hex-block`、`hex-hazard`，各 `-96.webp` / `-192.webp` |
| 路徑 | Claude 匯入 `public/battle-assets/hex/` |

**底色**：棋盤底是 `#0b111a`，格線 `#2f3f4f`。貼圖請在這個底上測試。

**不要畫進去**：格線、可行走高亮、路徑箭頭、座標數字、單位、陰影投射到鄰格。
這些全部由程式畫。

**辨識性**：五種要在 90 px 下分得出來，而且**不能只靠顏色**。
建議 open 低對比碎石、cover 低矮沙包（水平線條）、high 斷台頂面（邊緣有高差暗示）、
block 高聳實牆（最暗、紋理最密）、hazard 工業毒蝕（不規則斑塊）。
程式會另外疊 ▢ ▲ ☣ 符號，但貼圖本身的輪廓差異仍是第一層。

## 2. 角色棋子

**本輪不需要 GPT 出新圖**。程式直接用既有的 `head` 頭像（128×128），
在其上生成圓形／菱形底座、職責徽章、HP 條與蓄力層數。

需要 GPT 提供的只有一份 **manifest 對應**：
哪個 `assetId` 對應哪個敵方職責，以及哪些是「共用身分示意」。

| 項目 | 規格 |
| --- | --- |
| 棋子顯示直徑 | 62 px（@1x），約為六角寬的 0.69 |
| anchor | 六角中心，往上偏移 4 px（讓 HP 條落在格內下緣） |
| 底座 | 程式生成：我方圓形 `#7fd6a4`、敵方菱形 `#e08a76`，倒地轉灰 `#4a5563` |
| 遮擋排序 | 依 row 由小到大繪製，同 row 依 col。棋子只會蓋到自己那一格與下方相鄰格的上緣 |
| 頭像來源 | 沿用 `public/battle-assets/report/portraits/<assetId>-head.webp`，不需新檔 |

**明確不要**：把正面立繪壓扁當俯視人形、轉向／行走／倒地逐格動畫。

## 3. 特效

**全部由程式以向量線段實作，GPT 不需出圖。** 規格記錄於此供對照：

| 事件 | 表現 | 時長 |
| --- | --- | --- |
| 雷射 | 細直束 `#9fd6ff` | 160 ms 淡出 |
| 霰彈 | 三道短線扇開 `#ffd9a0` | 160 ms |
| 火焰 | 短錐 `#ff9a4d` | 220 ms |
| 電漿 | 單發粗點 `#b6a0ff` | 200 ms |
| 重槍 | 連點 `#ffd9a0` | 240 ms |
| 爆彈 | 短粗線 `#ffe6b0` | 180 ms |
| 未命中 | 同上但半透明並偏移 8 px | 120 ms |
| 倒地 | 灰階 + `×` 記號，無血 | 300 ms |
| 治療 | `+` 記號與數值，**不用紅十字白底** | 300 ms |

表現不決定結果：所有線段在結算之後才畫，碰撞與命中無關。

## 4. 姿態圖示（唯一請 GPT 出的 UI 素材）

| 項目 | 規格 |
| --- | --- |
| 數量 | 4 枚：`stance-hold` 盾牌、`stance-advance` 箭頭、`stance-flank` 彎箭、`stance-guard` 雙盾 |
| 格式 | **SVG**，單色路徑，`fill="currentColor"`，不含內嵌樣式或字型 |
| viewBox | `0 0 24 24`，線寬 2，端點圓角 |
| 最小可辨尺寸 | 16 px。請在 16 px 下確認四枚輪廓不互相混淆 |
| 路徑 | Claude 匯入 `src/components/icons/stance/` |

職責徽章**本輪不需要**：沿用現有 lucide icon 系統。

## 5. 驗收方式

Claude 匯入時會逐檔重驗：格式、尺寸、alpha、容量、bleed 邊緣非透明。
之後在 `#0b111a` 底上以 90 px 實際尺寸排出 11×9 棋盤截圖給使用者確認。

不符規格的檔案會退回並附上實測數字，不會「先接進去再說」。
