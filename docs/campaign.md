# 黎明星球戰役

單一星球的永久收復戰役，入口位於戰略地圖頂部；原年度戰線、軍隊數量與資源價格不變。

## 循環

完成任務／子任務／飛昇儀式 → 1 行動點 → 選擇據點和攻勢 → 確定推進 → 據點加成與收復勳章。
一般任務及子任務以 ID 去重；重複任務及每項儀式以本機日曆日去重。既有完成紀錄不追溯補發。
起始 0 點，沒有部隊也能使用偵察。所有出擊不耗兵、不清空進度。三據點全部 100% 時顯示「黎明守護者」勳章；本版不提供重置或重複刷獎。

| 攻勢 | 行動點 | 推進 | 專長 |
| --- | --- | --- | --- |
| 偵察 | 1 | 20 | 不需部隊 |
| 步兵 | 1 | 25 | 補給港 +15 |
| 裝甲 | 2 | 45 | 防禦線 +25 |
| 禁軍 | 1 | 25 | 指揮部 +15 |

補給港收復後所有攻勢 +5；防禦線收復後對指揮部 +10。任一前哨收復才可攻擊指揮部。兵種資格計算預備隊與所有駐軍，不改變部署。

## 儲存與部署

`game_state.campaign` JSONB 儲存行動點、去重事件、各據點進度、最近 30 則紀錄。後端啟動時 `server/src/db/init.ts` 會新增欄位；必須部署／重啟後端並確認 migration 成功後再使用新版前端。
STC 匯出包含戰役，匯入舊版備份不覆蓋目前戰役。自動同步失敗會每 5 秒重試；戰役變更會防止舊輪詢覆蓋，完整狀態寫入依序執行。沿用既有整份狀態 API，尚不支援多裝置同時修改衝突合併；請勿同時開多個裝置出擊。
任務寫入與遊戲狀態寫入仍是既有的兩個 API，並非資料庫原子交易；離線完成後請保持頁面開啟等待同步，不承諾離線關頁可保留。

## 驗證

- `npm run build`，`npm --prefix server run build`
- `node --test tests/campaign.test.cjs tests/campaign-persistence.test.cjs tests/visual-data.test.cjs`
- `/visual-preview.html` 提供三項一次性的示範任務，可取得 3 點並用步兵收復補給港；示範資料不連後端，重新整理即重設。
- 單元測試覆蓋去重、兵種資格、消耗、加成、上限及備份還原；模擬路由測試覆蓋新建／更新／讀取與使用者範圍。正式 PostgreSQL 和登入環境讀寫未實測。
