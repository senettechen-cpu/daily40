## 1. 基礎設施（本階段變動）

| 項目 | 狀態 |
| --- | --- |
| GitHub | `senettechen-cpu/daily40`（私人）；舊 remote 保留為 `old-emperor40k` |
| Zeabur | Lightsail Tokyo 2C 4GB；服務 `api`＋`web`＋PostgreSQL |
| 部署方式 | **GitHub 整合**，push 自動部署 |
| 登入 | 自建帳密（scrypt + JWT），已移除 Firebase 與 LINE |

**踩過的雷，不要重試**：

- Zeabur「任意 Git」來源在此帳號恆回 `INVALID_ARGUMENT: Dockerfile is required`，即使 Dockerfile 存在、Deploy key 可讀、分支正確。改用「GitHub 儲存庫」整合才成功。
- **`NODE_ENV` 絕不可設 `production`**：`server/src/db/index.ts` 會據此對資料庫啟用 SSL，而 Zeabur 內網 PostgreSQL 不支援，會直接連不上。
- `backup-*.sql.gz` 與 `data/` 是資料庫傾印檔，已加入 `.gitignore`，不要 `git add -A` 進去。

### 名冊（v1.5 §4）

- 角色實例制取代兵種擁有制。角色有唯一 ID、姓名、出身、職責、XP、傷勢。
- 開局免費配發六名卡迪安（中士、三名步槍兵、醫療、工程）＋「第一特遣隊」編成。
- 可存多套編成，**名冊無人數上限**，每場最多部署六人。
- **招募**：用軍需買人。普通星界軍 160／專職 200；其他出身需授權（`personnel_authorizations` 表）。

### 軍械庫（v1.5 §2）

- 18 項目錄，v1.5 候選價格。裝備是唯一實例，綁定角色。
- 欄位上限：主武器 1、副武器 1、護甲 1、工具 2。出身限制、授權限制。
- 回收退還**實付的 25%**（向下取整）；配發品實付 0，回收 0，無法憑空生錢。

### 戰鬥（v1.5 §6 / GPT r6）

- 真實編成與配裝餵進模擬：等級生命（每級 +2% 基線，十級 +18%）、護甲、命中。
- **甲殼甲**：護甲 40 ＋ 移動速度 ×0.90（1.2→1.08 格/秒），只影響位移，係數在出發時算一次不逐 tick 相乘。
- **G1 門檻**：當日需完成一項今日核心才能開始新行動；休息日／豁免可出戰但不發獎（D2 未做，兩者恆為 false）。
- **伺服器裁決**：`POST /api/operations` 由伺服器自建編成、自跑模擬、自寫 XP，客戶端只重播。客戶端無法宣稱任何結果。
- **XP**：出戰者勝 60／敗 40／超時 20，全員同額不按擊殺；備訓最多 4 人領 50%，上限截斷在 Lv8（1750 XP）。**無每日場次上限**（使用者決定，見 §4）。
- **俯視戰術圖**：戰報上方可展開，預設收合。讀每 tick 的歷史位置快照，地形直接讀 `shared/battle/terrain`。

### 架構

- 模擬與規則已移入 `shared/`，前後端共用：`shared/battle/{terrain,sim,deployment,gate,xp}`、`shared/roster/`、`shared/armory/`、`shared/rewards/`。
