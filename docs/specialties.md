# 專長系統（2026-09-27）

使用者在 grill 第 7 題定案，內容由 Claude 設計並附模擬數據（見 [balance-decisions.md](balance-decisions.md)）。
程式：`shared/roster/specialties.ts`（定義與選擇規則）、`shared/battle/turn/loadout.ts`（固定效果）、`shared/battle/turn/engine.ts`（情境效果）。

## 規則

- **三個槽**：Lv3、Lv6、Lv9 各開一個，每槽兩個選項二選一。
- **選了就鎖定**：選之前會跳確認框；沒選的槽沒有效果，也不會自動幫你選。伺服器以「槽位仍與檢查時相同」為條件寫入，兩個分頁同時選也只會成功一次。
- **分組**：突擊（步槍兵、火焰、電漿，以及改造中的候選人）、精準（精準射手）、支援（醫療、工程、通訊）、指揮（中士），外加阿斯塔特一組。
- **授銜**：成為阿斯塔特時，人類專長清空，三個槽依等級重新開放，改從阿斯塔特組選，選了一樣鎖定。
- **戰報重播**：專長效果隨出戰隊伍一起存進作戰紀錄，重播和伺服器結算完全一致。
- 每個專長都是改變打法的取捨（站定或移動、貼近或固守、自己或身邊的人），不是單純加傷害。

## 已知限制

- 精準組與阿斯塔特組沒有在平衡預設隊伍裡出現（預設隊伍沒有精準射手，也沒有阿斯塔特），這兩組的強度是比照其他組設計，還沒有實測數據。
- 「戰地急救」「急進指令」「死守陣線」這類支援型效果在模擬裡效果偏小；它們依賴站位，模擬的預設站位不一定用得到。
