# 節奏模型與裝備價值表（2026-09-27）

系統審查 P1-4、P1-5 的分析報告。這兩份是**量測與建議**，本文件沒有改動任何數值；要不要依建議調整，另外決定。

## 一、節奏模型：第幾天會到哪裡

**方法**：`node scripts/sim-pacing.cjs 300`。以實測勝率表（`balance-decisions.md`，敵方支援上線後、每格 200 場）模擬玩家的每一天，
收入、XP、價格都直接讀遊戲裡的常數。三種玩家各跑 300 次，取中位數。

主要假設：買裝備照固定順序（防破片甲 → 入門混編 → 甲殼甲 → 電漿 → 重武器＋第三件甲殼甲），錢夠且已解鎖就買；
每場都打下一個能打的據點，輸了當天不再出戰；每天只培養一位候選人。

收入：今日核心每項 +10、記帳每筆 +20、里程碑 +20、開局 +40。XP：勝 60、敗 40、首次收復 +40；Lv10 需 2700 XP。

### 觀察

1. **一章只夠玩 4–7 週**：穩定型玩家約第 35 天打完最終首領。對天天用的生活 App 來說，戰役內容消耗得很快，
   這正是「戰役結束後的持續內容」需要優先規劃的原因。
2. **飛昇是最長的線**：第一位阿斯塔特授銜約在第 52–105 天，是目前唯一能撐到兩三個月的目標。
3. **等級升得比裝備快**：Lv6 約第 11 天，電漿槍卻要到第 20 天；到 Lv10 時，老兵級裝備常常還沒買齊。
   原因是敗戰也給 40 XP、出戰次數沒有上限。
4. **記帳收入是做任務的兩倍**：記帳每筆 +20、每天 3 筆＝60；今日核心每項 +10、每天 3 項＝30。
   從設計意圖看，「完成生活任務」才應該是主要收入，記帳是輔助；目前反過來了。
5. **世界 1 首領太快**：新帳號第 2–5 天就能打下 1-4，第一位候選人也跟著在第一週出現。

**方法**：以「全員雷射槍＋手槍＋防破片甲」為基準，一次只給一個人換一件裝備
（`GEAR="c2=shotgun" node scripts/sim-battles.cjs <關卡> flak 100`），量 8 個世界 1–3 關卡的勝率變化（百分點）。
每格 100 場，誤差約 ±5–10，看平均比看單格可靠。

### 觀察

1. **重武器組最划算**（平均 +10），前提是現行「一人就能全速射擊」；若改成兩人組，量測顯示它會變成負價值（見 `balance-decisions.md`）。
2. **甲殼甲、電漿槍是有用的**，電漿的價值集中在擊倒目標（2-3 +20）與載具關卡。
3. **火焰器是情境武器**：教徒群的關卡 +11～+12，其他關卡負值。這符合設計，但畫面上沒有告訴玩家（戰前威脅提示現在會提醒）。
4. **一半的裝備幾乎沒有價值**：醫療工具、工程工具、通訊工具、整備一階、精準雷射槍、霰彈槍平均都在 ±1 以內。
   買了不會變強的東西，會讓「賺軍需買裝備」這條主線失去意義。
