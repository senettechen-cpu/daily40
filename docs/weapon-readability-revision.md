# 射程與即時武器裝備修正

2026-09-21，接續 cultist-sidearm-revision.md；本文件覆蓋其射程及驗證數據。

- 步槍射程 7 → 12、精準槍 9 → 15、霰彈槍 3 → 5、火焰器 3 → 4；敵軍槍手 6 → 11。
- 近戰敵人移動間隔 0.5 → 1.0 秒／格。不是改成不會近戰；視線遮擋或突破火線仍能觸發副武器。
- 可開火且沒有迫近威脅時優先射擊；冷卻期間仍可尋找掩體。保留掩體方向性、視線遮擋與移動後才能開火。
- 裝備欄原本只有固定主武器資訊，現在新增獨立主／副武器槽、手持狀態、高亮、圖示、射程、傷害、攻速。小隊卡及肖像同步 actor.sidearm。
- 手槍图層放大至 1 倍、改握持位置，主武器 .85 倍；換武器時獨立圖層重新淡入；戰場顯示手槍標籤。基底仍是無武器角色圖集，沒有烘焙長槍。
- 手槍沿用低傷害與切換代價，攻擊顏色改讀副武器資料，不再繼承主武器顏色。

驗證：建置成功；31 項測試通過，包括跨戰場射擊、至少六次主武器攻擊後才可能接戰、手持圖層／裝備槽渲染同步與切回主武器。

固定種子基本隊：32.6 秒完成、四人存活、未被貼身；100 種子 100 勝、平均 36.2 秒。這是教學原型，長期難度與多關卡平衡尚未完成。
